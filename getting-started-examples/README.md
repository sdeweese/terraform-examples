# Getting Started Examples

- [VLAN, single file](01-vlan-single-file/): provider configuration, variables, and VLAN resources together in one `main.tf`.
- [Multi-device ACL, split files](02-acl-multi-device/): provider aliases, variables, and ACL resources in separate Terraform files.

Both examples configure Cisco IOS XE devices over NETCONF. Review each example's README and plan carefully before applying changes to a switch.
